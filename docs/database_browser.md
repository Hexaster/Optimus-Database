# 中文数据浏览页面

在项目根目录、`fosun` Python 环境运行：

```bash
conda activate fosun
python scripts/browse_database.py --demo
```

浏览器打开 <http://127.0.0.1:8765>。`--demo` 使用已有 `.pipeline-demo` 独立演示数据库，必要时启动它；不会重新抽取、入库或执行迁移。演示目录尚未创建或已清理时，也可启动页面，显示零计数和空列表。端口占用时增加 `--port 8766`。

读取 `.env` 或环境变量配置的数据库时，去掉 `--demo`：

```bash
python scripts/browse_database.py
```

页面包含：

- **数据总览**：来源数、实体数、证据数、匹配检查数量和最近入库批次。来源数按来源类型与来源编号去重，不等于全部都是文章。
- **实体与证据**：搜索名称、别名、来源编号和记录内容；浏览结合域、CAR 骨架、制造工艺、三者组合与独立证据。详情可跳转到关联证据，并查看每条导入来源记录及已保存的抽取依据附件。
- **匹配检查**：分别查看匹配结果待确认、类似工艺、匹配信息冲突。并排比较记录，显示入库时保存的判断理由、缺失项与冲突字段。按来源记录计数，不等同于去重后的实体数。

每次打开页面、切换列表或点击 **刷新数据** 都查询当前数据库，不是静态导出的 HTML。已有数据库连接失败时页面明确报错，不展示缓存成功状态。详情中的抽取依据是数据库已保存的文本，不读取任意本地文件，也不自动打开 PDF/XML；未保存的附件不会凭空生成。

页面仅绑定本机 `127.0.0.1`，所有数据库查询使用只读事务，无编辑、合并或删除入口，不调用模型。源文本以纯文本显示。停止网页服务使用 `Ctrl+C`，不会停止或删除数据库。浏览期间可以继续入库；演示结束清理数据库后，网页服务继续运行：保留页面布局，自动归零计数、清空列表并关闭失效详情。每 3 秒检测一次演示库状态，演示库恢复后自动恢复查询，新入库的数据可点击“刷新数据”查看；普通连接故障仍报错，不会伪装为空库。

此版适用于本机演示。数据列表每页 20 条，最近批次显示 8 条；单条匹配详情最多显示 50 个候选并标明总数。匹配判断来自入库时的审计快照，候选实体内容读取当前数据库；页面不会重新裁决身份。不同描述的差异高亮只是帮助阅读，实际判断以保存的匹配理由为准。
